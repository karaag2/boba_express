# Boba Express Niamey - Landing Page

Une landing page moderne et interactive pour Boba Express Niamey, conçue pour offrir une expérience utilisateur premium et optimisée pour le SEO.

## Caractéristiques
- **Animations Scroll-Driven** : Une bouteille de boba interactive qui s'anime au défilement (ProductBottleScroll).
- **Design Brutaliste Moderne** : Couleurs vibrantes, typographie audacieuse et ombres portées marquées.
- **Optimisation SEO** : Stratégie complète en français ciblant le marché de Niamey, Niger.
- **Performance** : Construit avec Next.js 15+, Tailwind CSS 4 et Framer Motion.
- **Responsive** : Design adapté aux mobiles pour les citadins de Niamey.

## Structure du Projet
- `app/` : Routes et mise en page principale.
- `components/` : Composants UI réutilisables (ProductBottleScroll, Navbar, Hero, etc.).
- `public/frames/` : Les 192 images webp utilisées pour l'animation de défilement.
- `seo_plan.md` : Détails de la stratégie SEO implémentée.

## Installation
```bash
npm install
npm run dev
```
